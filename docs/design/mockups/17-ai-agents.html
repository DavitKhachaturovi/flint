Notes for Davit

Choices I made (Proposed)

  • Off: nothing is hidden or dimmed. You can hide lists, pick read-only and limits, and add apps before the first agent ever connects; and Recent agent changes must stay usable after you turn agents off in a hurry, so you can still undo. The Off state here is a first start (both lists empty) to show the empty lines.
  • The status is a line under the switch's note with a 7 px dot: filled white while on, accent while read-only, an outline when off, white text and an outlined dot while paused. Resume sits left of the switch, as Reset tips does in About.
  • Read-only dims the Limits row (45 %, not clickable) and its note says why; the chosen level is kept for when read-only goes off.
  • Limits' numbers are a floating card beside the hovered level (the menus' ground and shadow), "In one request" and "In an hour" split by a hairline. I read the delete limits as per request (they are listed with the request limits in AGENT-01).
  • Connect an app is a list under its row, like Settings → Claude's folders: the app's name, a faint mono "Connected" while it is connected now, the quiet fallback (Copy setup) before the main action (a secondary button), as D-104 puts the primary action last. Claude Code's command shows in a well under its row with the note about the skill and the flint command.
  • Skill: not installed → "Install for Claude Code"; installed and current → "Installed for Claude Code · version 1.8.0" and no button; an older copy (Read-only state) → its version and Update.
  • Recent agent changes: one 38 px row each: the agent (secondary), the change, the time in mono, Undo. Undone: the row's text goes faint and Undo crossfades to "Undone". New entries slide in from above (Simulate in the bar). The pause toast's Review scrolls here.
  • Hidden from agents in the right-click menu sits next to Sync with Google Drive (both per-item switches), checked on the right like the sort menu's check. Show to agents folds the row away.
  • The sheet: the Anywhere in Windows group's label says "Click a key to change it"; "(changeable)" leaves its action names. The recording and warning messages are a line under the row, D-102's exact words.
  • Capture's Hotkeys link row turns into the warning while another app holds a hotkey ("Ctrl+Alt+X is used by another app, so it doesn't work. Choose another in the shortcuts sheet."), so a taken hotkey still shows where people look for it.
  • Keyboard shortcuts' one row is named "All shortcuts", its note "Also with ? or Ctrl+K. The four hotkeys that work anywhere in Windows change there."

Questions and spec points

  • Skill's Update button vs AGENT-04. AGENT-04 says Flint updates a copy it installed by itself, so an Update button would only ever show for a copy Flint didn't install (which it must not touch) or one it failed to update. Proposed: the version line only, Update only after a failed automatic update. Your brief asked for "Installed · version 1.8.0 with Update"; shown once, on an older copy.
  • Settings' search opening the sheet "with the filter filled" (D-186). Filled with "hotkey" or "shortcut", the sheet would show "No shortcut matches." Proposed: the search shows the row; clicking it opens the sheet, filtered only when the words match something in it, and the Anywhere in Windows group also answers to "hotkey" and "global" (the Find state does this). Opening the sheet while you type would take the caret away, so it never opens by itself.
  • The conflict message. Your brief's "Ctrl+Alt+X is used by another app. Choose another." is shorter than D-102's text; I kept D-102's ("… so it doesn't work. Choose another.") as D-186 asks for the same messages.
  • Capture's section name. Kept "Capture & hotkeys" in the index: its link row still answers "where are my hotkeys". Rename to "Capture" if you prefer.
  • Toast after undoing. "Undone, except 1 task changed since" carries Undo (03 §4: toasts carry Undo when reversible, and AGENT-07 puts the undo on Ctrl+Z's stack).
  • No mark on hidden items in the sidebar (as synced items lost their cloud, D-163); only the menu's check and Settings show it. Say if you'd like a quiet mark.
  • Other status lines (not in a state; Proposed wording): pipe name taken: "Off · Another program is using Flint's agent channel, so agents can't start." PATH skipped (Q14): "The flint command isn't on your PATH (it was too long to change safely). The apps above use its full path, so they work."
