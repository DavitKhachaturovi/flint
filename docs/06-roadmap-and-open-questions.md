## 1. Risk-first build order (replaces the separate spike, D-18)

There is **no throwaway spike**. Instead, the three riskiest pieces are built first, **as production code**, at the start of M2/M3, each with measurable acceptance checks. If one fails, it is found in the first days, and only that piece is reworked. Test on an **average laptop with a Teams call active** (including full-screen), not a dev workstation.

| # | Risky piece | Acceptance check |
|---|---|---|
| R-1 | **Popup latency** (CAP-01, CAP-10) | Hotkey → popup visible with focused cursor **< 50 ms** (hard limit 100 ms) over a full-screen Teams call; no blank/white flash; appears on the active monitor; focus returns to the previous app after Enter/Esc. |
| R-2 | **Capture-selection** (CAP-07) | Selected text is captured from a normal window (browser, Teams chat, normal terminal); the original clipboard is restored; hotkey modifiers don't corrupt the Ctrl+C; from an **admin** terminal the failure is detected and the popup opens empty with the hint. |

## 6. Google's side of sync (SYNC-01, D-161): Davit's one-time setup

Users only sign in with Google; the Cloud project and its client ID are set up once, by Davit, in his own Google account. Claude walks through it when the build is ready for it; what to do:

1. **Project:** console.cloud.google.com → project picker → **New project**, name "Flint" (no organization needed).
2. **Drive API:** APIs & Services → Library → **Google Drive API** → Enable.
3. **Consent screen (Google Auth Platform):** Get started → app name **Flint**, Audience **External**, a contact e-mail, accept the policy. **Branding (D-162):** user support e-mail `flintnotes.support@gmail.com` (shown to everyone who connects, so not Davit's own address); home page `https://flintnotes.app`; privacy policy `https://flintnotes.app/privacy/`; authorised domain `flintnotes.app` (verified in Google Search Console); no logo (a logo needs brand verification); no Terms of Service. *Later (10 Nov 2026, after the release):* the logo `assets/icon/flint-icon-120.png` uploaded and the brand verified (the consent screen shows Flint's name and logo); Terms of Service `https://flintnotes.app/terms/` (D-162), since without it Google's consent screen says it isn't showing links to Flint's terms. Google won't publish to In production until Branding has the home page and privacy policy on a domain the developer owns, so publishing waits for the site (WEB-01); until then the app stays in **Testing** with Davit as a test user (sign-ins expire after 7 days, fine for the preview).
4. **Scope:** Data Access → Add or remove scopes → `https://www.googleapis.com/auth/drive.file` ("See, edit, create and delete only the specific Google Drive files you use with this app"), non-sensitive, so no verification beyond the basic one.
5. **Client:** Clients → Create client → type **Desktop app**, name "Flint desktop" → Create. Copy the **client ID** (`…apps.googleusercontent.com`). Its **client secret** (`GOCSPX-…`, Clients → Flint desktop → Client secrets) is needed too (D-161, found 10 Nov 2026) but never goes into the repository: Davit puts it in the repository secret `GOOGLE_CLIENT_SECRET` (`gh secret set GOOGLE_CLIENT_SECRET`) for releases and in `apps/desktop/.env.local` as `FLINT_GOOGLE_CLIENT_SECRET=GOCSPX-…` for his local builds (git-ignored). If it is ever abused (someone else's program using Flint's client), Clients → Flint desktop lets him add a new secret and disable the old one; the next build carries the new one.
6. **Publish:** Audience → **Publish app** → In production. In Testing, refresh tokens expire after 7 days (everyone would have to sign in again weekly) and only listed test users can sign in.
7. The client ID goes into `apps/desktop/src/main/sync/google.ts` (committed: desktop client IDs are public by design, D-161 Q7).

**Status (10 Nov 2026):** steps 1–5 done (the project, the Drive API, the consent screen with the support address, the scope, the Desktop client); its ID is in `google.ts`; the app is in Testing with Davit as a test user until the site is live and Branding's links are set (step 6). Without an ID the app would say "Not set up in this build" in Settings → Sync. The first real sign-in (development build, `My Drive › Flint (development)`) is the check that the setup works.
