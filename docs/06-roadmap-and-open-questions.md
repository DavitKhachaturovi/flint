## 5. The move to GitHub (D-135; planned after v1 in D-132, brought forward)

Flint is Davit Khachaturovi's personal project, open source under MIT, public at [github.com/DavitKhachaturovi/flint](https://github.com/DavitKhachaturovi/flint).

1. **Scrub (0.9.0, done):** the code, tests, fixtures, mockups, screenshots and docs hold no private names: no employer, client or colleague names, internal URLs, work emails or private ticket and CI run numbers. Examples use neutral names (the list `Unicorn`, `Alex`, `acme`, `Contoso`, `*.example`). Public products stay (the Azure DevOps, GitHub and Jira link recognisers, Teams, Discord, OneDrive).
2. **History:** rewritten once, before the first push, from a kit kept outside the repository (it lists the strings it removes, so it must never be committed): the same replacements in every file of every commit and in every commit message, Davit's GitHub noreply address as the author, the files that only made sense on the old host removed, the screenshots' older versions stripped; then a search of the rewritten history that fails on any listed string, and a secrets scan (gitleaks).
3. **One branch:** `main`, the rewritten `m4-lists`; no other branches and no tags until `v1.0.0`. Work continues in a fresh clone at `C:\Forge\flint-repo`; the old working copy never pushes to GitHub.
4. **Releases (built in 0.9.1, D-136):** GitHub Releases with auto-update (APP-06), GitHub Actions for CI and releases; the Privacy sentence in Settings → About says Flint only contacts GitHub to check for updates. What to set up on GitHub (permissions, rulesets, 2FA) is in the kit's notes and the report of D-136.
5. **Code signing:** later, through the SignPath Foundation (open source) or a Certum certificate.
6. **1.0.0** is the first release on GitHub Releases; until then builds stay 0.9.x.
7. **Trademark (Q-11), settled 8 Nov 2026:** WIPO's Global Brand Database has 58 "Flint" records for software, several active, in unrelated markets; the name stays, an accepted risk.

**From now on:** nothing private enters the repository (CLAUDE.md), and the build stays plain npm scripts that run anywhere.
